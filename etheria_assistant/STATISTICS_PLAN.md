# 当前功能范围与预案

## 当前优先级

1. 可靠记录胜负：先用真实一胜一负对照结算字段，再用另一场验证，最后启用自动识别。字段未确认前保留手动标记，未知不计失败。
2. 角色对位统计：某角色所在队伍遇到某对方角色时的胜/负/平/未知、胜率及样本数；低胜率优先展示。
3. 两人搭配统计：两名角色同队上场时的整队胜率及样本数；高胜率优先展示。
4. 维护现有对局显示、库存存档、界面和历史兼容。

不继续开发自动BP推荐、自动选人、克制推荐分数或旧BP软件直连。已有BP观测记录保留兼容，不扩展解析计划。统计不依赖完整BP顺序：双方最终上场阵容和真实胜负就能开展当前两项统计。

## 统计口径

“角色X对角色Y胜率”指X所在队伍遇到包含Y的对方队伍时的整队胜率，不是X与Y单挑。一个阵容含多个对手时，该场分别贡献到相应的对位组合。角色X/Y相同的镜像对位不列入榜单。

两人搭配没有方向，X+Y与Y+X只保留一组。同队重复英雄编号不重复计数。双方都出现同一组合时，两个队伍样本分别计数，因此样本单位是队伍，不是相互独立的战斗。

结果未知、平局分别列出，不计入胜率分母。最少胜负样本默认5，可调到1观察初期记录；这只是显示筛选，并不意味着5个样本就足以证明克制。选择关注角色后，对位榜仅以该角色所在队伍的胜率排序；搭配榜显示包含该角色的双人组合。

“双方队伍”统计全部观察到的阵容。“仅己方”依据用户选择的对方队伍推导己方；没有明确选对方A/B的记录会排除，避免默认猜测己方。模式、赛季/版本分组仍由用户填写，角色变体仍按精确ID分别计数。

## 源器价值评分预案（未实现）

建议延后。它能节省整理大量装备的时间，但对当前对位/搭配统计的帮助较小，且源器属性的单位和主副属性尚未完成核对。现在直接评分可能让错误解码看起来很精确。

以后若做，只扩展源器价值评分：

- 先核对属性类型、单位、数值缩放、部位及强化档位。
- 支持用户调整速度、暴击、生命、防御等权重，并按输出、辅助、生存等用途区分方案。
- 展示每项属性得分和最终总分，记录评分方案版本；同一件装备可有多个用途评分。
- 分数是整理和筛选参考，不声称适合所有角色，也不替代实际矩阵和配装需求。
- 本次不添加评分、打分权重控件、自动配装或一键处理装备。
