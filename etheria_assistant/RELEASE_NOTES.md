# 2.11.32-calc-test · Windows 计算器测试版

- 更新下载超时或传输中断时自动重试，最多尝试三次。设置页可打开 GitHub 发行页手动下载完整包。
- 首页、速度条和头像编辑预览支持按角色编号找回内置头像。本地自定义头像优先。
- 完整包附带 300 个角色编号映射和内置图集，可离线使用。

## 2.11.31 已发布的更新功能

- Windows EXE 启动后会后台检查同渠道新版，发现更新时可选「立即更新」或「稍后」。旧版可在「连接与设置」中检查更新，直接下载最新版完整包。
- 新版启动检查通过后，自动清理这次升级的旧程序文件和下载缓存。本地对局、库存、映射和设置继续使用，升级前保留数据库备份。

## 2.11.30 已发布的界面和数据改动

- 首页新增跨两栏的「面板速度」排行，按速度从高到低显示双方头像和数值。双方昵称在归属确认后与「己方／敌方」同时显示。
- 新增「首动推演」，显示首个角色预计到达 100% 时的行动进度。推演计入芙蕾雅触发戍卫时的开局拉条，同速且开场进度相同标为随机先动。冲坡效果仍待实战验证。
- 默认主题改为暖黑古金，可在「连接与设置 → 界面主题」切回经典紫黑。Windows 11 主窗口标题栏、边框以及配装页的练度概览随主题切换。
- 客户端内置角色映射从 104 个编号增至 300 个，随完整更新包下发。西尔维娅的 32501、32502、32503 统一使用「娅」。本机自定义映射继续优先。
